# ドット絵折りソルバー

このプログラムの実行にはpython 3が必要です
動作確認はしておりません
【重要】このプログラムは汚いです
【重要】このプログラムは不完全です
【重要】計算に数分かかる場合があります
このプログラムを使用したことでいかなる不利益が生じても，作者は責任を取りません
このプログラムが正常に動作しなくても，作者は責任を取りません

------------------------------------------------------------------------

使い方：
1: play.batを起動
2: ドットを入力
3: circuit=32であることを確認
4: executeをクリック

解が見つかれば展開図が出力されます

------------------------------------------------------------------------

【ヒント】
デフォルトのspeed=500で解が見つからない場合，speed=1に変更してみてください
計算に時間がかかる代わりに，全探索します
speed=1でも見つからない場合，解が存在しません
